# Sandėliukas

Telefonui skirta programėlė: skenuoji produktų brūkšninius kodus, matai, ką jau turi namie, dedi į sandėliuką, suvalgai ar išmeti, žiūri pirkimų istoriją. Produktų informacija iš [Open Food Facts](https://world.openfoodfacts.org).

Veikia kaip svetainė, duomenys saugomi tik telefone.
